# Clickwise affiliate programs and deals

This data-only bundle connects DeepSeek Harness (DSH) to the public Clickwise MCP server to find affiliate programs, deals, and tracked links. No API key is required. It uses the DSH MCP client with Streamable HTTP and contains no executable plugin code.

Links returned by these tools are affiliate links: if someone buys through them, the publisher who shares them may receive a commission from the store.

## Add the index in DSH

After the index is published:

1. Open **Plugins** and enable **Custom plugin indexes** under **Experimental plugins**.
2. Choose **Discover → Add index source → URL** and enter the URL below:

   https://softdevfz.github.io/dsh-plugin-index/index.json
3. Select `clickwise-mcp`, choose version `0.1.0`, review its Git source, and confirm installation. Enable the installed bundle to use it.
